## 1 平台与公共基线

### 1.1 硬件与位流

| 项 | 值 |
|---|---|
| 器件 | xczu27dr (PYNQ-ZU 板) |
| 位流 | `WC/soc.bit` 13,495,559 B（2026-11-25 06:30:08 UTC） |
| 硬件描述 | `WC/soc.hwh` 965,689 B |
| 基线对比 | v102 位流 13,338,759 B，差值 15,700 B = 新增 amp/sum 逻辑 |
| RFDC | Fs 4096 MSPS，插值/抽取 4 → 字率 **256 MSPS**，DAC/ADC NCO 均 1000 MHz，DAC 数据宽 8 bit |
| 软件 | PYNQ 4.0.0，python 3.12.3 |

### 1.2 信号链

```
PS(AXI-Lite) -> bkt_forwarder(BKP 包) -> nco_gen(PL DDS) -> diver_demo -> DAC0
                                                             |
                                         模拟环回（-14.8 dB，反相）-> ADC0 -> adc2axis -> AXI DMA0 -> PS
```

**反相特性**：环回后频谱上的频率符号与设定值相反（设 +20 MHz，测得 -20 MHz）。这是模拟链路反相导致的已知现象，不影响功能判定，本文所有"实测频率"均按此约定读。

### 1.3 上电必做（顺序不能反）

```python
lab = Lab()
lab.clock(force=False)   # 配 LMK04828：等 PLL2 LD=1、SYSREF MUX=3
lab.powerup()            # 强制重下位流 + rf_reinit()
```

**坑**：位流刚上电时 RFDC 可能残留坏状态（DAC tile state=0x7 而非 0xF，抓回来全是 0x00000000），此时 LMK 已锁也照样没数据。`powerup()` 里的 `ol.download()` + `rf_reinit()` 能恢复，恢复后所有 tile 都是 state=15/pll=1/powerup=1。

### 1.4 公共基线：PL 侧 DDS 单音（77-2 的核心，76-1 的单音部分与它同一套）

**实现**：48 bit 相位累加器，每个 256 MHz 采样拍 `cnt0 <= cnt0 + D`；正弦表 1024 点 16 bit，表项取 `cnt0[47:38]`，Q 路索引 +256 即 90° 相移。

**寄存器写入顺序**（BKP base=1200，AXI-Lite 基址 0x80010000，每包：data→index→1→0）：

| 偏移 | 名称 | 说明 |
|---|---|---|
| base+1 | DDS_scale | 幅度右移量，0=满幅，每 +1 约 -6 dB（老路径） |
| base+2 | DDS_CH_enable | 每通道 1 bit，本设计 8 通道 |
| base+3 | init_phase | 16 bit 初相，需连写 20 包（前 8 包有效） |
| base+4 | D 表 | 每通道 2 包：先高 32 位、后低 32 位；8 通道共 16 包，**必须连续写** |
| base+5 | req_done | 写完 D 表后写 1 |
| base+0 | DESR | **必须最后写 1**，否则数据进错 bank |

**调用**：

```python
lab.program(20.0)             # 单音 20 MHz（内部等 3.2 s = 3 个 ref_pps 沿）
xc, r = lab.capture(65536)    # DMA0 抓 65536 点
```

![图 1【ADC 接收】单音 20 MHz：上半为 I/Q 时域波形（前 200 点，两条正交正弦），下半为 65536 点频谱，单峰在 -20.000 MHz，幅度 83.75 dB re 1 LSB，带内无杂散](wave_single.png)

**读图**：时域两条正弦严格正交（相位差 90°），说明 I/Q 两路相位关系正确；频谱单峰、无镜像、无杂散。这是 76-1（单音）、76-2（扫频起点）、77-2（分辨率）三项共同的基线。

## 2 Topic 76-1：单音 / 多音 / 幅度调节

### 2.1 原始要求

> 76-1 DDS 单音/多音/幅度调节 —— "与 77-2 同一套"

原始 IP 只有单音 + 6 dB 步进的 `DDS_scale`，**多音做不到**，幅度也无法连续调节。

### 2.2 本版改动（v103）

| 新增 | 说明 |
|---|---|
| base+11 `amp_en` | 幅度乘法使能；0 = 走老的 `DDS_scale` 右移路径（与 v102 逐位等价） |
| base+12 `amp_q15[8]` | 每通道 16 bit 线性增益，`32767` = 1.0 满幅；连写 8 包 |
| base+13 `sum_en` | 多音求和使能；0 = 各通道独立输出（单音），1 = 8 路相加送 DAC0 |

RTL 关键行：`wire signed [31:0] I_mul = rd_data1 * amp_q15;`，`amp_en ? I_mul >>> 15 : rd_data1 >>> DDS_scale`；求和树为三级流水（17/18/19 bit）+ `sat16` 饱和，代价 +16 DSP，DAC0 比其它通道晚 3 拍（11.7 ns）。

**切换全部靠寄存器，一次综合永久可用**：

```python
lab.program(20.0)                                      # 单音
lab.multitone([20.0, 30.0, 40.0, 50.0], amp=4096)      # 4 音
lab.program(20.0, ramp=1, chirp_len=25600, d_step=4295000000)   # FMCW
```

## 3 Topic 76-2：FMCW 连续扫频

### 3.1 原始要求

> 76-2 FMCW 连续扫频 —— "现有 IP 做不到"

原 IP 的 D 是"每 PRF 一个常数"，由 `update_pluse`（timer_delay）周期重载，没有斜率项；靠 PS 通过 AXI-Lite 逐拍改频也不可能（总线速率远低于 256 MSPS）。**这是真正的功能缺失，必须改 RTL。**

### 3.2 本版实现

`nco_single_gen.v` 增加端口 `ramp_en`、`D_step[47:0]`、`chirp_restart`；内部**双累加器**（避免每拍乘法）：

```
step_acc <= step_acc + D_step;        // 每 clk
cnt0     <= cnt0 + (D_start + step_acc);
```

等价相位 **phi(n) = D0*n + D_step*n(n-1)/2**，二次项即线性调频；每个 chirp 起点由 `chirp_restart` 清零 `cnt0`，保证相位相干。

| 寄存器 | 名称 | 说明 |
|---|---|---|
| base+6 | ramp_en | 1 = 扫频模式 |
| base+7 | chirp_len | 每 chirp 点数 N（32 bit） |
| base+8 | D_step[31:0] | 每拍频率增量低 32 位（有符号） |
| base+9 | D_step[47:32] | 高 16 位（补码，负斜率写 0xFFFF） |
| base+10 | dead_len | 每 chirp 后空闲拍数，输出停在终止频率 |

**公式**（f 单位 Hz，字率 256e6）：

| 量 | 公式 |
|---|---|
| 频率字 | D = f * 2^48 / 256e6 = f * 1.0995e6 |
| 带宽 | B = D_step * N * 256e6 / 2^48 |
| 周期 | T = (N + dead_len) / 256e6 |
| 斜率 | k = D_step * 256e6 / 2^48 |

### 3.3 步骤

```python
lab.program(20.0, ramp=1, chirp_len=25600, d_step=4295000000, dead_len=0)
xc, r = lab.capture(65536)
print(lab.chirp_stats(xc, period_samples=25600, chirp_samples=25600))
```

分析用"跳变点检测 + 分段相位差分"：相位差分给瞬时频率，检测周期回卷点，只对 chirp 段做线性拟合（`chirp_samples` 参数排除死区）。

## 4 Topic 77-1：RFDC 内置 NCO

### 4.1 原始要求

> 77-1 RFDC 内置 NCO 出单音 —— "基本可以，但有一个不确定点"

### 4.2 原理与实现

RFDC 的 NCO 是**混频器**，不是信号源：它只搬运频率，必须有输入信号。所以 PL 侧喂一个**恒定直流**（D=0、CH 使能），让 DAC 的 NCO 单独完成上变频；接收端 ADC 的 NCO 固定在 1000 MHz 完成下变频，基带看到的峰就是两者之差。

```python
lab.program(0.0, scale=0)          # PL 输出直流
xrfdc.set_nco_mhz(True,  0, 1000.0)   # ADC NCO 固定 1000 MHz
for mhz in (900, 950, 1000, 1050):
    xrfdc.set_nco_mhz(False, 0, float(mhz))   # 改 DAC NCO，立即生效（内部走 evt_src）
```

### 4.3 实测

![图 6【ADC 接收】RFDC 内置 NCO 扫频：四条谱线分别对应 DAC NCO 900/950/1000/1050 MHz，基带峰依次为 +100/+50/0/-50 MHz；1000 MHz 那档落在 0 Hz 直流，已被去均值滤掉，故只剩余泄漏](wave_nco.png)

| DAC NCO 设定 | 基带实测峰 | 幅度 |
|---|---|---|
| 900 MHz | **+100.000 MHz** | 83.9 dB re 1 LSB |
| 950 MHz | **+50.000 MHz** | 85.4 dB |
| 1000 MHz | **0 Hz（直流）** | 被去均值滤除 |
| 1050 MHz | **-50.000 MHz** | 87.1 dB |

误差 < 0.01 MHz，`mixer_get` readback 一致，改完立即生效。

**结论：RFDC 内置 NCO 的频率由软件任意设定，实际辐射频率 = 设定值。**

> 关于"不确定点"：如果指的是**频率能不能随便设、设了准不准**——本次已用真机闭环证明（误差 < 0.01 MHz）。如果指的是**输出质量**（相位噪声、杂散、谐波、真实输出功率），那必须上频谱仪，本板的自环回链路只能看到基带复原信号，无法评价射频指标。

**勘误**：早前的 `fmcw_tone_report.md` 第 9 节把这张表的符号写反了（写成 -100/-50/0/+50），正确关系是本表，绝对值与幅度不受影响。

## 5 Topic 77-2：频率分辨率专项

单音功能已在 1.4 节验证，这里只测分辨率——即"最小能分辨多大的频率变化"。

### 5.1 测量方法

1M 点采集（4.096 ms @ 256 MSPS），相位斜率法估频；把记录切 8 段各算斜率取**中位**（抗偶发相位滑动）；测量用 **A-B-A 交替**（0 Hz → 目标 → 0 Hz）抵消 LO 慢漂。

### 5.2 实测

| 设定步进 | 实测增量 | 偏差 | 结论 |
|---|---|---|---|
| **+10 Hz** | -10.012 Hz | **0.012 Hz** | 清晰可分辨 |
| +1 Hz | -1.328 Hz | 0.33 Hz | 临界，受环回测量底噪限制 |
| +0.1 Hz | +0.027 Hz | 0.13 Hz | 已淹没 |
| +0.01 Hz | -0.052 Hz | 0.04 Hz | 已淹没 |

- 零点重复性（同设定 4 次）：跨度 **0.07 Hz**；干净采集段间 std **0.05 Hz**
- 1M 点记录里偶发一次**相位滑动**（段间 std 跳到 113 Hz），属 DMA/ADC 毛刺，不是 NCO 的问题 → 长记录分析必须用分段中位
- **寄存器分辨率由构造保证**：D 为 48 bit、字率 256 MSPS → 1 LSB = 256e6/2^48 = **0.91 uHz**；写 1 Hz 差 D=1,099,512，写 0.1 Hz 差 D=110，均可表示

**结论**："DDS 频率分辨率 0.91 uHz"成立；1 Hz 以下受限的是**环回测量手段**（LO 漂移约 0.1 Hz + 偶发毛刺），不是 DDS。要真正测到 1 Hz 以下，需要示波器长时间窗口或频谱仪。

## 8 限制与后续

| 类别 | 项 | 说明 |
|---|---|---|
| 必须外部仪器 | 输出功率、相位噪声、谐波/SFDR、模拟带宽 | 自环回看不到射频指标 |

| 软件 | 寄存器/API 速查一页纸 | 可随时补 |
