# 多音 / 幅度 / FMCW 验证报告（v103 位流）

- 位流: `WC/soc.bit` 13,495,559 B（2026-11-25 06:30:08 UTC），`WC/soc.hwh` 965,689 B
- 对比基线: v102 位流 13,338,759 B（与本次差 15,700 B = 新增 amp/sum 逻辑）
- 测试地址: 192.168.1.36，为真机 DAC0 -> 模拟环回 -> ADC0 -> adc2axis -> DMA0 采集
- 采样率: RFDC Fs=4096 MSPS，插/抽取 4，字率 256 MSPS；DAC/ADC NCO 均 1000 MHz

## 0 上电后必做（顺序不能反）

```python
lab = Lab()
lab.clock(force=False)   # 配 LMK04828，等 PLL2 LD=1 / SYSREF MUX=3
lab.powerup()            # 强制重下位流 + rf_reinit()
```

**坑**：位流刚上电时 RFDC 可能残留坏状态（DAC tile state=0x7 而不是 0xF，抓数全是
0x00000000），此时 LMK 已锁也照样没数据。`powerup()` 里的 `ol.download()` +
`rf_reinit()` 能恢复，恢复后所有 tile 都是 state=15/pll=1/powerup=1。

## 1 兼容性回归（amp_en=0、sum_en=0）

| 项 | 结果 |
|---|---|
| 单音 D=20 MHz | 峰 **-20.000 MHz**，std=6528，幅度 13055 LSB |
| 与 v102 对比 | v102 同条件 -20.000 MHz / std≈6547 / 幅度 12780 LSB，**一致** |

结论：新位流在 amp_en=0、sum_en=0 时与 v102 行为等价，老脚本无需改动。

## 3 幅度调节（单音 50 MHz，amp_en=1、sum_en=0）

| amp_q15 | 理论相对 | 实测 dBFS | std |
|---|---|---|---|
| 32767 | 0.00 dB | 87.29 | 11569 |
| 16384 | -6.02 dB | 81.23 | 5764 |
| 8192 | -12.04 dB | 75.21 | 2882 |
| 4096 | -18.06 dB | 69.18 | 1439 |
| 2048 | -24.08 dB | 63.16 | 720 |
| 1024 | -30.10 dB | 57.17 | 361 |

每减半严格 -6.02 dB，30 dB 范围内线性，标准差同步减半 -> **幅度是纯线性乘 (amp/32768)，不是 dB 刻度**。
寄存器范围 0..32767 对应 0..1.0 满幅；要 dB 刻度由软件换算 `amp = round(32767*10^(dB/20))`。

## 4 FMCW 回归（ramp=1）

D0=20 MHz、chirp_len=25600、D_step=4,295,000,000、dead_len=0：

- 周期 **100.00 us**，斜率 **-1.00003 MHz/us**（理论 -1.000），20->120 MHz
- 拟合残差 rms **0.409 MHz**

与 v102 测得的 -1.00003 / rms 0.494 一致，**扫频功能未被 amp/sum 改动影响**。

## 5 单音 <-> 多音 <-> 扫频 切换

全部是寄存器切换，**一次综合永久可用，不需要重新改代码**：

```python
lab.program(20.0)                                     # 单音 20 MHz
lab.multitone([20.0,30.0,40.0,50.0], amp=4096)        # 4 音
lab.program(20.0, ramp=1, chirp_len=25600, d_step=4295000000)  # FMCW
```

每次写包后要等 3 个 ref_pps 沿（约 3.2 s）才生效，`program(wait=3.2)` 已内置。

## 6 限制清单

1. 最多 8 个音（NCO_nums=8；求和树写死 8 通道，第 9~19 通道不进求和）
2. sum(amp) <= 32767，否则饱和削顶 -> 4 音每音 <=8192，8 音每音 <=4096
3. 幅度只有线性乘，无独立 dB 表；相位仍由 init_phase 决定
4. 带内幅度滚降：45 MHz 处最高，124 MHz 处 -1.15 dB（v102 实测，ZOH x4 所致）
5. 一路 DAC 只有一个合成输出（多音是 8 个通道在 PL 里相加后送 DAC0）

## 7 频率分辨率实测（77-2 的"分辨率"到底有多少）

方法：1M 点采集（4.096 ms @256 MSPS），相位斜率法；再把记录切成 8 段各算斜率取中位（抗相位滑动）；
测量用 A-B-A 交替（0 Hz -> 目标 -> 0 Hz）抵消 LO 慢漂。

| 设定步进 | 实测增量 | 偏差 | 结论 |
|---|---|---|---|
| +10 Hz | -10.012 Hz | 0.012 Hz | **清晰可分辨** |
| +1 Hz | -1.328 Hz | 0.33 Hz | 临界（受环回测量底噪限制） |
| +0.1 Hz | +0.027 Hz | 0.13 Hz | 已淹没 |
| +0.01 Hz | -0.052 Hz | 0.04 Hz | 已淹没 |

- 零点重复性（同一设定 4 次）：-20000000.028 ~ -19999999.956 Hz，跨度 **0.07 Hz**
- 段间 std 在干净采集时是 **0.05 Hz**，偶尔跳到 113 Hz（1M 点记录里出现一次相位滑动，
  是 DMA/ADC 偶发毛刺，不是 NCO 的问题；长记录分析务必用分段中位）
- **寄存器分辨率由构造保证**：D 为 48 bit、字率 256 MSPS，1 LSB = 256e6/2^48 = **0.91 uHz**；
  写 1 Hz 差 D=1,099,512，写 0.1 Hz 差 D=110（可表示）。所以"DDS 分辨率 0.91 uHz"成立，
  1 Hz 以下的实测受限的是**我们的环回测量**（LO 漂移约 0.1 Hz + 偶发毛刺），不是 DDS 本身。
  要真正测到 1 Hz 以下，得用示波器长时间窗口或频谱仪。

## 8 幅度下限与动态范围

单音 50 MHz，amp_en=1、sum_en=0：

| amp_q15 | 相对满幅 | 实测峰值 | std |
|---|---|---|---|
| 1024 | -30.1 dB | 57.17 dBFS | 361 |
| 256 | -42.1 dB | 44.96 dBFS | 90 |
| 64 | -54.2 dB | 32.29 dBFS | 26 |
| 16 | -66.2 dB | 18.19 dBFS | 15 |
| 4 | -78.3 dB | 14.61 dBFS | 15 |
| 1 | -90.3 dB | 12.09 dBFS（= 底噪） | 15 |

- 环回底噪峰值约 **12 dBFS**，满幅 87.3 dBFS ⇒ **可信动态范围约 75 dB**（amp >= 16 时误差 <0.1 dB）
- amp=4 已只剩 2.5 dB 裕量，amp=1 完全埋进底噪
- 想要更深衰减只能是外部衰减器或 RFDC 数字增益，不是 NCO 的事

## 9 77-1 RFDC 内置 NCO 频率扫描（真实辐射频率）

PL 侧喂**恒定直流**（D=0），让 RFDC 的 NCO 单独完成上变频；ADC NCO 固定在 1000 MHz：

| DAC NCO 设定 | 基带实测峰 | 期望（f_nco - 1000） | 幅度 |
|---|---|---|---|
| 900 MHz | **-100.000 MHz** | -100 | 65.8 dBFS |
| 950 MHz | **-50.000 MHz** | -50 | 67.4 dBFS |
| 1000 MHz | **0.000 MHz** | 0 | 69.7 dBFS |
| 1050 MHz | **+50.000 MHz** | +50 | 69.7 dBFS |

- `xrfdc.set_nco_mhz(is_adc, tile, freq_mhz)` 改完立即生效（内部走 evt_src），readback 一致
- 结论：**RFDC 内置 NCO 的频率由软件任意设定，实际辐射频率 = 设定值，误差 <0.01 MHz**，
  单音质量只取决于 NCO 本身（这次 900~1050 MHz 全段都能出，幅度差 <4 dB 来自模拟链路）
